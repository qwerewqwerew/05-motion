대상: `snapboard/scene-1~4.png` (직접 열어 확인) + `snapboard/src/*.html` + `base.css`.
대조 문서: `docs/motion.md` · `docs/video.md` · `docs/design.md` (모두 열어서 대조). 부품 값은 `src/parts/*.html`과 대조.
이 판정은 **스냅보드(정지 화면) 단계 기준**이다. 움직임 · 시간 항목은 영상 단계에서만 판정할 수 있어 아래에서 분리했다.

## 2. 유도값 3건 판정 (builder 보고: 폰-부품 간격 90px, 장면 4 중앙 정렬, 폰 위치)

| 값 | docs에 있는 값? | 판정 |
|---|---|---|
| 폰-부품 간격 90px (`--gap`) | **아니오, 새 숫자.** docs 어디에도 폰-부품 간격이 없다. `space-large` 32 × 2.8 = 89.6 → 90으로 만든 유도값. 게다가 design.md 4장은 "영상 레이아웃(장면 배치 · 여백)에는 쓰지 않는다"고 적었고, video.md 5장의 "간격도 같은 배율"은 부품 안쪽 간격이 대상이다. base.css 주석의 근거(space-large)는 docs 규칙과 맞지 않는다. | 놓는 위치 · 정렬이라 critic 기준상 **세지 않음(통과)**. 단 근거 주석은 부정확하다고 기록. scenes.md도 "좌표는 비트 시트에서" 정한다고 했고 폰-부품 간격 값은 어느 docs에도 없다. |
| 장면 4 중앙 정렬 | 숫자 없음. flex 가운데 정렬. PNG 실측: 아이콘 x 821~1099 · y 401~679, 중심 (960, 540)으로 캔버스 중앙과 일치 | 위치 · 정렬, **통과**. 새 숫자 아님 |
| 폰 위치 (`padding-left: (1920-461-90-980)/2` = 194.5px) | 상수는 없고 폰 461 · 부품 980 · 캔버스 1920(docs 값) + 위 90으로 계산한 값. PNG 실측 폰 x 195~656 | 위치 · 정렬, **통과**. 새 상수는 아니나 90에 의존하므로 90의 주의가 같이 걸린다 |

참고(세지 않음): 폰 바깥 크기를 video.md 4장은 461×956이라 적었으나 토큰대로(429/928 + bezel 14×2 + 선 2×2) 계산하면 461×960이다. PNG 실측도 y 60~1020 = 960. docs 쪽 표기 불일치이고 builder는 토큰 값을 그대로 썼다.

# verdict: app-intro (영상 단계)

대상: `video.mp4`(1920×1080 · 30fps · 150프레임, ffmpeg로 확인) + `video-src/video.html` + `video-src/render.js` + `frames/`(f003 · f030 · f046 · f052 · f100 · f140 직접 열어 확인, mp4 f052와 PSNR 42.7dB로 일치 확인).
대조 문서: `docs/motion.md` · `docs/video.md` (열어서 대조), `refs.md` 체크리스트.

## 2. 움직임 숫자 대조 (video.html 코드 ↔ motion.md)

| 값 | video.html | motion.md | 일치 |

| 곡선 4개 | `standard .4,.14,.3,1` · `entrance 0,0,.3,1` · `exit .4,.14,1,1` · `spring .34,1.56,.64,1` | 1장 곡선 표 | 일치 (bez 함수의 x/y 제어점 순서도 맞음) |

| emphasis 12f | 진행 바 `standard`(10, 12), 장면 2 `spring`(7, 12) | `motion-emphasis` 400ms = 12f, standard / 3장 예외로 spring | 일치 |
| stagger 3f | 부품 시작 t=3 (폰 0 뒤) | 7장 `motion-110` 3f | 일치 |
| 카운트업 12f | `standard`(10, 12), 0 → 29700 | 7장 `motion-400` 안, ease-standard | 일치 (f100 `₩28,333` 중간값, 끝값 29,700) |
| hold 15f | 장면 1: 22→37, 장면 2: 19→34, 장면 3: 22→37, 장면 4: 7→22 | 4장 `hold-short` 15f, 직전 움직임(12f)보다 짧지 않음 | 일치 |

## 3. 새 값처럼 보이는 곳 판정

| 값 | 숫자로 세나 | 이유 |
|---|---|---|
| 투명도 전환 0 ↔ 1 (등장 · 퇴장) | 세지 않음 | 처음 · 끝 상태이고 중간에 고정되는 값이 없다. 길이 · 곡선은 모두 motion.md 값. docs에 투명도 수치를 정한 곳은 없으나 길이 · 곡선 · 색 · 크기에 해당하지 않는다. |
| 진행 바 끝값 0.5 (시작 0) | 세지 않음 | `src/parts/mission-card.html`의 기본값 "0.5 = 피그마 값"과 같다. 시작 0은 끝 상태. |
| 카운트업 끝값 29,700 (시작 0) | 세지 않음 | `src/parts/stat-card.html`의 문구와 같다. |

| 간격 90px (`--gap`, 폰 왼쪽 시작점 `(1920-461-90-980)/2`) | docs에 없는 값이다. 단 위치 값이라 critic 기준상 세지 않음(통과) | 스냅보드 판정과 같다. 주석 "space-large 32 x 2.8"은 design.md 4장(영상 레이아웃에는 쓰지 않음)과 맞지 않아 근거가 부정확하다고만 기록한다. |
